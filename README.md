# FloodRescu Relief

A modern Next.js web application providing emergency flood assistance and relief resources.

## Features

- 🚨 **Emergency Request System** - Submit urgent help requests with location and contact details
- 📞 **24/7 Hotlines** - Quick access to emergency services and flood relief hotlines
- 🏠 **Resource Directory** - Find shelters, food, water, medical services, and financial aid
- 🛡️ **Safety Information** - Essential flood safety tips and guidelines
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Fast Performance** - Built with Next.js 16 and React 19 for optimal speed

## Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm 10.x or higher

### Installation

1. Clone the repository:
```bash
git clone https://github.com/haibhse18/FloodRescu-Releif.git
cd FloodRescu-Releif
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the production application
- `npm start` - Start the production server
- `npm run lint` - Run ESLint to check code quality

## Tech Stack

- **Framework**: Next.js 16.1.1
- **UI Library**: React 19.2.3
- **Styling**: Tailwind CSS 4.x
